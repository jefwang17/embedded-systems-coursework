# Embedded Systems and Programming Coursework

A curated collection of programming, embedded-systems, electronics, and digital-design projects completed during my electrical and computer engineering coursework.

This repository contains selected source files and project materials that demonstrate experience with C, C++, AVR assembly, KiCad, and VHDL. Compiled programs, IDE caches, submission archives, and instructor-provided materials have been excluded.

## Coursework

### ESE 124 — C Programming

- C programming fundamentals
- File input and output
- Arrays, structures, functions, and pointers
- Stack implementation
- Maze command-interpreter final project

### ESE 224 — C++

- Object-oriented programming
- Classes and header/source separation
- File processing
- Data structures
- Multi-file C++ programs

### ESE 280 — Embedded Systems

- AVR assembly programming
- Input/output and push-button handling
- Serial communication
- LCD and barcode-related exercises
- Digital schematics created with KiCad

### ESE 382 — Digital System Design

- VHDL design descriptions
- Combinational and sequential logic
- Seven-segment display decoders
- Testbenches and simulation
- Counters, registers, and timing circuits

## Repository Structure

## Notes

This is a curated portfolio repository rather than a complete archive of course materials. Generated files, executable binaries, IDE metadata, assignment archives, exam solutions, and instructor-owned documents are intentionally excluded.

Each project remains educational coursework and may depend on course-specific hardware, development tools, or input files.
